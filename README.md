# This repository contains the labs for the Web Technologies course

## Web Technologies Labs

Labs 2 & 3: Foundations & Routing – Focused on environment setup (venv), Django installation, and understanding the MVT pattern by mapping URLs to views and rendering dynamic content.

Labs 4 & 5: Templates & Visual Styling – Implemented Template Inheritance to build reusable layouts, managed static files, and styled advanced HTML components like nested tables using CSS.

Labs 6 & 7: Models & Data Filtering – Introduced Django Models and SQLite database integration, focusing on performing migrations and using QuerySets to filter and retrieve specific data.

Labs 8 & 9: Forms & CRUD Operations – Developed Django Forms for user input handling and validation, and implemented full CRUD (Create, Read, Update, Delete) functionality to manage records.

Labs 10 & 11: Model Relationships – Mastered database relationships, including One-to-One and Many-to-Many mappings, with a focus on displaying relational data in structured tables.


Lab 12: Authentication & Messages – Integrated Django's authentication system (Register, Login, Logout), enforced login permissions for views, and implemented a user notification system using the Messages framework.
